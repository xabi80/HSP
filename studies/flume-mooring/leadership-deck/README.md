# Leadership briefing — flume mooring design

A 16-slide briefing, for leadership, on how the flume mooring was designed and what it achieves.
It is written in plain language and built from MOORING-SPEC rev C.1.

## Where things are

| File | What it is |
|---|---|
| Online deck (the master) | https://claude.ai/artifact/GiVfP1SYpeHmXdK8PH2VnS. It is private: share it from its **Share** menu. |
| `leadership-briefing.pdf` | A PDF of the slides, rendered locally from the files below by `render_pdf.py`. |
| `SPEAKER-NOTES.md` | The speaker notes of every slide. |
| `deck.json`, `slides/*.html` | The deck's source, copied from the online deck: the index and one file per slide (notes in each slide's `<aside>`). |
| `render_pdf.py` | Re-renders the PDF and the notes from the source (headless Edge). |
| `leadership-briefing.pptx` | *Not yet here.* Export it from the online deck (**Share › Export › PowerPoint**) and save it in this folder. |

The two images are the project's own figures, `../figs/plan_platform.png` and
`../figs/elevation_cluster.png` (generated by `mooring_figures.py`).

Every number comes from the mooring study:
- the specification: `spec_statics*.json`, `extreme_set.json`, `attachment_sweep.json`;
- the moored-vs-free runs: `viewer_rows_revc/`.

## Updating

1. Edit the online deck.
2. Copy its files back into this folder: `deck.json` and `slides/`.
3. Run `python render_pdf.py`.

The online deck is the master; this folder is a copy.
