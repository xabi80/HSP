Installation and test sequence

1

Install the operational set; set T0 by the calm tilt (≈ 0.70°/N, cluster and platform) or tension (buoy). Static pull and decays against the FloatSim predictions.

2

Response series, H ≤ 0.12 m, on the operational set.

3

Swap to the extreme set: same anchors, attachments and at-rest tension; set it by tension or the 1° calm tilt, never by length.

4

Static pull before every extreme series: K ≥ 33 N/m (cluster) or ≥ 146 N/m (platform) confirms it.

5

Extreme series in increasing H, 0.2 → 0.35 → 0.5 m; stop near 0.9 m of offset or a line near its working load.

6

The buoy's extremes last, with a height ramp; stop on any yaw growth.

Mooring design study · MOORING-SPEC rev C.1

23

The test sequence follows from everything before. Install the operational set and check it: the calm tilt is the pretension gauge for the cluster and platform, about 0.7 degrees per newton, and the buoy's line tension is measured directly. The static pull and the free decays are compared with the tabulated FloatSim predictions, allowing for creep. Run the response series. Swap to the extreme set at the same anchors and at-rest tension, setting it by tension or tilt because its pre-stretch is only a few centimetres. Before every extreme series, the static pull confirms the extreme cords are on. Build the extreme heights up gradually with live offset monitoring, and stop before the tracking limit or a line's working load. Run the single buoy's extremes last, with a height ramp, watching yaw: three of its cases have no reliable FloatSim prediction.
